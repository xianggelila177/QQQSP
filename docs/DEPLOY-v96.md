# QQQSP 2.16.0 / v96：免费美股成交流与轮询

适合个人自选面板。保持现有 Node 单进程、共享行情状态、网页 SSE 和 API；没有新增运行时 npm 依赖、付费套餐或交易功能。

## 接入

在服务器私有 `.env` 配置自有 `FINNHUB_TOKEN`，即可启用 Finnhub 美股成交流。`FINNHUB_MAX_SYMBOLS=30` 是保守的本地上限，可按账户真实权限调整；超出部分继续轮询。订阅一个证券的多个页面和 Agent 共用上游连接。密钥不能写入源码、前端或文档。

网站批量轮询继续补充，不因免费流存在而停用。缓存每秒参与选择，但真正上游调用仍遵守原来源 TTL、429 和 Retry-After。Finnhub 的可用证券、覆盖及延迟以账户权限为准，不声明全市场 SIP；原 Alpaca 接入也保留，IEX 单一交易所不能取代全市场行情。

## 本版改动

- 修复免费流健康时网站备用缓存最长60秒不更新；采用有界公平队列，不让前几只股票一直占满并发。
- 新成交事件在进入报价计算前短暂合并，并保证在途读取期间的最后一次更新不会丢失。最新状态立即供网页及 API 共享。
- 区分成交时间、成交接收时间、价格来源检查时间、流连接帧时间。低成交频率不等同断线；来源更换时清理旧精度和延迟元数据。
- 新成交可保留已确认同证券、同币种、同交易日的网站开高低、成交量和昨收，并独立标注统计来源。跨日或依据不明时不沿用旧统计计算涨跌。
- Finnhub/Alpaca 重连清除旧连接确认，拒绝旧帧、超大或错误消息；连接构造和发送异常进入有界退避，供应商错误内容与凭据不进入日志。
- Alpaca 静默时通过合法订阅确认检查连接，不将 REST 成功当作 WebSocket 心跳。Finnhub 使用其应用心跳及成交消息检查连接。
- API `/api/v1/quote-stream` 默认持续连接，移除每60秒断开；SDK移除默认65秒终止。仍保留逐秒鉴权、密钥撤销、连接及缓冲上限。
- 断线重连后发送当前快照；API每秒合并输出，不承诺逐笔无损回放。行情未变化时以15秒心跳维持连接。
- 连接状态与实际价格来源分别展示。数据源未声明的固定延迟保持未知，缓存报价不冒充实时成交。

## 升级

先保存原 `.env`、状态、服务及代理配置；使用独立 release 目录。切换时短暂停服务取得一致的 shared 备份，添加 Finnhub 凭据，原子切换 current 后启动原服务。保持原域名、端口、只读密钥、管理员密钥、自选和采样目录。

定向验证：`npm run test:v96`。本轮不要求全套压力或浏览器冒烟测试。发布只需确认程序启动、版本资源、原配置保留及已配置的流连接状态。上游是否出现新成交必须单独报告，不能由WebSocket连接成功推出。

v95可作为上一版回滚目录。回滚只切换应用链接，保留当前shared数据及密钥治理文件，避免恢复已经撤销的密钥；新增Finnhub凭据本身与v95兼容。
