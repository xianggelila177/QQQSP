## 二、测试驱动修复过程

本轮先写6个回归测试并在2.2源码运行，得到6失败0通过；再实现期货身份、检索、类型、目录与历史，得到6通过。证据为 `regression-before.log` 与 `regression-stage1.log`。

完整回归第一次暴露新增目录数量与原断言不一致、公开请求标识触发秘密扫描的问题。按真实新增目录更新断言；公开标识改为具名常量并说明来源，没有修改扫描器或加入全局忽略。

浏览器进一步发现两个测试设施问题：初次使用了错误的搜索容器选择器；“更多搜索”测试默认返回429，使后续Yahoo报价正确进入共享冷却。分别纠正选择器和健康场景的上游搜索样本，429行为继续由专用测试断言，不重置生产冷却。

视觉检查另发现真实代码遗漏时区字段，导致无历史的期货不能显示已有报价采样。新增用例在修改前失败（`futures-sampling-before.log`），补齐Chicago时区偏移后通过；浏览器断言具体月份卡片显示一个真实时间点且无虚构成交量。

发布复查还补充了目录备源的实际调用节奏测试：原来虽然显示30秒，通用缓存仍按5秒失效。失败证据见 `futures-fallback-cadence-before.log`；缓存增加本次读取的有效期参数后，备源30秒内不重复探测主端点。原缓存默认行为及关闭行为保持不变，最终全量回归再次通过。

## 三、浏览器覆盖

测试使用实际构建包和实际本地Node HTTP/SSE服务器。浏览器策略不允许直接访问回环，因此使用仅在测试中注入的转接桥；桥只转发请求响应，不生成业务数据。测试上游样本由 `futures-browser-server.mjs` 提供，生产 `server.js` 不引用该文件。

验证包括：NQ0W两个相关候选；更多查询实际返回的NQ26Z/NQ26U候选；东财连续与Yahoo连续分别加入；四档有效蜡烛；股指点数不转人民币、不乘20；无来源分时时的采样；320、375、768、1024、1440、1730像素无整体横向溢出；浏览器无脚本错误。

测试图截图带有“测试样本，非真实行情”标识。年龄测试每场景是短时前台采样，不能外推为浏览器后台、睡眠或长期运行的毫秒级保证。

## 四、网络和生产边界

本构建环境针对东方财富报价、期货目录和Yahoo图表的真实API请求均在域名解析阶段失败（`live-network.json`）。已核实的是公开产品页面与开源适配格式，不是目标服务器上实时行情可用性。

最终交付校验另外记录干净解压、逐文件校验、正式入口启动、本地搜索、静态资源和正常退出。没有执行用户服务器的systemd、隧道切换、真实授权账户或全天稳定性测试。部署后必须用 `ops/futures-smoke.mjs --live` 检查实际来源。

## 五、验收结论

源码、构建产物和已执行自动化测试可复现；报价及历史的生产可达性保留为目标服务器验收项。所有源失败时应展示错误或旧数据状态，不生成“看起来正常”的假K线。
