# QQQSP 2.4 测试报告

## 一、验收结论

本报告对应应用版本2.4.0、静态资源序号77。完整保留回归 **91个文件通过、0失败**；核心测试 **107个用例通过、0失败、0跳过**。核心测试相对2.3的79个新增28个用例。语法、版本、前端构建、预压缩及配置一致性检查 **312个脚本通过**；秘密扫描无发现。

所有结果均为实际运行记录，不把旧版本日志改名当作本轮结果。原43个已经退役的旧套件仍单列，不计为通过，本轮没有新增退役项。

## 二、环境与测试范围

环境为 Linux、Node.js 22.16.0，浏览器为系统Chromium，通过Python Playwright执行。应用运行不需要Playwright或第三方npm依赖。Node24为建议部署环境，本轮未再执行Node24矩阵。

普通回归、宏观HTTP测试均执行实际程序。浏览器执行已构建的生产前端；上游财经响应受控模拟，网络受限时使用仅测试的本地HTTP转接。模拟器放在 `tests/v2/`，正式入口没有导入它，安装器不会复制测试样本。

构建环境上游访问有DNS失败，网页查询Yahoo亦曾出现429，因此不把网页文档可读或模拟HTTP成功当作真实上游全部可用。未执行真实付费日历账户、目标服务器systemd安装、隧道切换、容器构建及长期稳定性验证。

## 四、故障反馈与修复过程

初始2.3基线：保留回归90通过、1失败，核心79通过。唯一失败是旧中继测试的极短本地时间期限，后续完整运行在未修改其断言情况下通过。

首次修改后完整回归：87通过、4失败。三处是合法新增字段或模块数导致旧断言失配，分别更新主题数（4到5）、官方摘要字段以及前端模块数（20到21）。另一处真实缺陷是给保留旧新闻反复写入新的评估时刻，导致缓存语义改变；修复代码移除此字段，而非删除该测试。

宏观真实HTTP组合测试发现：Google主题结果较少时，旧Yahoo新闻兜底触发认证/搜索429，共享冷却连带阻断美债与美元价格。修复正式组装根为 `allowYahooFallback:false`，保留独立服务兼容默认值，HTTP重测通过。

浏览器发现全球目录移到底部后继承负上边距，空卡片布局出现重叠。通过页面邻接样式修复，并重测六种宽度。跨站脚本测试曾因注入到已捕获fetch的错误测试位置未生效，修正测试桥的注入位置后通过；不把这个测试装配错误描述为生产XSS漏洞。

发布检查发现原期货验收脚本固定写死版本76，改为读取交付包VERSION并加入真实子进程测试，避免下一个版本误报。

## 五、浏览器最终结果

四个浏览器入口均在本版重新运行，全部退出码0。不同浏览器入口测试数据独立，不能将测试价格解释为当前市场行情。

| 场景 | 结果 |
|---|---|
| 宏观位置 | 宏观在卡片前，全球市场目录在卡片后；六种视口无页面整体横向溢出 |
| 宏观分析与日历 | 条件标签、原油/纳指对象分离、同窗观察、发布前预期记录、主题过滤通过 |
| 宏观安全与请求 | 转义不可信标题/链接，浏览器无脚本异常；折叠期间不产生新的宏观轮询 |
| 股票历史 | 日、周、月、年切换；429/空主源备源恢复；分时和采样切换；冷却重试通过 |
| 期货 | NQ相关搜索、加入自选、具体月份、四档K线与采样通过 |
| 年龄正常工作线程 | 最大相邻显示变化1002.1毫秒 |
| 年龄工作线程静默 | 最大相邻显示变化999.8毫秒 |
| 年龄工作线程报错 | 最大相邻显示变化1002.2毫秒 |
| 健康行情推送期间 | 对应浏览器测试中行情HTTP轮询0次 |

年龄每种场景采样约4.6秒，这是前台短时结果，不是后台冻结、休眠或长期精确计时保证。跨资产15分钟比较通过注入可控时间测试，不声称进行了15分钟真实市场追踪。截图带模拟数据标识。

六种视口：320、375、768、1024、1440、1730像素。最终证据：`browser-results.json`、`chart-browser.json`、`futures-browser-results.json`、`macro-browser.json`、各 `*-final.log` 与 `macro-browser-release.log`。
