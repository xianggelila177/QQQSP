## 三、特意没有声称完成的内容

概况：以下项目仍属于待办，避免使用者把开发候选包理解为全部需求已经生产验收。

没有把价格 HTTP 读取周期改为一秒；没有保证每秒一定有真实成交；没有完全移除 Yahoo 历史和慢数据；没有全面拆分所有大文件或兼容单例；没有实现历史二次聚合缓存；没有新增完整官方最后成交规则；没有完成半开连接 ping／pong、权威订阅确认、多进程账户配额协调；没有真实行情账户联调、公开展示许可确认或生产部署。

保守日内统计合并仍需用精确前一交易日算法替换十日近似保护。原工作线程静默仍可能影响原网络调度，但不会再阻止独立年龄变化。更新来源后的历史曲线仍可能来自原源，页面会尽量说明，但完整历史换源需要按计划实施。

## 四、验证与总结

概况：本版是有实际修改和证据的后续开发基础，不是对生产可用性作无条件承诺。
