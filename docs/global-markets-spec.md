# 全球主要市场数据扩展规格

用户于2026-09-06确认：富时指数为英国FTSE100；在既有中国内地、美国、香港、日本、韩国基础上，加入英国、德国、法国、瑞士、荷兰、意大利、西班牙、加拿大、澳大利亚、印度、新加坡、台湾、巴西、墨西哥、南非。覆盖这些市场主要现货交易所的股票、ETF与代表指数。

本轮按明确列出的交易场所和Yahoo代码后缀支持，不把一个国家的所有次级交易场所、衍生品交易时段或付费实时权限统称为已支持。英国FTSE100必须有真实报价和图表验收；其他每个市场至少验证代表指数、股票、ETF的代码身份、报价与历史，并明确公开来源的字段缺失与延迟。不能用ETF价格冒充指数。

## 用户行为

- 搜索支持中文市场/指数别名、英文名称和完整证券代码；FTSE100可直接发现和添加。
- 搜索下方提供可展开的全球市场目录，按市场/地区浏览代表指数及股票、ETF示例；不在打开目录时启动全部证券订阅。
- 现有自选和币种偏好保持；添加沿用去重与12只上限。增加“原币”选择，指数显示点数，不参与换汇。
- 显示真实市场、交易所、源币种/子单位、来源检查时间和来源已声明延迟。未知交易时段、缺失行情、缺失换汇率均有明确状态，不能显示假零值或伪称实时。

## 正确性约束

1. 单一市场目录驱动识别、时区、主交易场所、代码别名和前端目录。未知后缀仍未知，非美股不能请求Nasdaq或腾讯美股备用源。
2. 交易日历来自交易所官方资料，维护明确覆盖日期、闭市、半日和特殊开市。IANA时区按被计算时刻处理DST。已公告特殊开市但尚未公告具体时刻时，记录为待确认，不推断闭市或编造时间。
3. 保留提供者原始价格单位和所有原始价序列：GBp/GBX表示GBP的1/100，ZAc/ZAC表示ZAR的1/100。仅在换算函数计算因子；不重写价格、OHLC或图表数组，避免双重缩放。指数始终为点数。
4. 延续FX约定：rates.USD为CNY/USD，其余标准币种为该币种单位/USD。原币不依赖FX。缺失某个币种只影响该币种转换；不能拼接不同参考日期/来源伪造完整汇率集。
5. 沿用有界队列、全局Yahoo熔断、已有缓存和恢复机制。FX每轮至多一次批量请求，单币种图表回退保持有界（不超过原有4次预算）；新增20市场不意味着启动20市场常驻轮询。
6. 测试先复现失败，再实现；最终保留全部既有检查和80%分层覆盖率门槛，不把模拟数据当作在线来源验证。
