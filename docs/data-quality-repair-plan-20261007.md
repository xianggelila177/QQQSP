# 数据质量修复清单（2026-10-07）

基线：v121 / `779d1d0`。本轮承接只读审计，先修复会造成误解的质量判断，再补充可核验的数据源。

## 实施与最小验收

1. **报价日期与来源**：以交易所日历的最近完成交易日识别旧报价；保留中国长假、周末和半日市的正确行为。仅比较证券、币种、会话及时间相近的报价，披露显著差异，不做盲目平均。API 保留成交统计独立来源、覆盖、时间精度和未知延迟。
2. **财务身份与内容日期**：每个 Naver 子响应均校验证券身份；抓取时间不替代报告期。古老报告、未知有效日期和可比口径的来源冲突有明确标记。估值刷新与报表缓存分开，保留来源数值与派生估计的区别。
3. **新闻**：标题情绪不等同于目标股票方向；有限并发合并多个来源并去重，统一出版方域名分类，保留未核验状态。
4. **市场覆盖**：核验台湾证券交易所公开接口的实际字段、日期、单位及证券身份，接入确有依据的日度估值。复现港股上游原始响应和解析链，修复确定的解析/路由问题。
5. **验证与记录**：针对审计反例编写回归测试，运行相关现有测试与构建检查。保存官方资料、有限实时探测和剩余能力清单，不用短时抽样宣称长期 SLA。

## 找源与准入方式

从交易所、监管机构、发行人和已有供应商的官方目录及文档发现接口，再检验真实响应。每个新来源记录证券身份、币种、单位、业务日期、报告期、更新频率、访问约束及失败行为。新来源只有在这些依据明确时参与对应字段选择；不因抓取成功就标记为最新或全市场。

优先核验 TWSE OpenAPI 日度资料；SEC EDGAR submissions/companyfacts 用于美国披露与报告期追溯，但需真实申报主体映射、符合规范的 User-Agent、财年/单位/修订处理，不能把原始 XBRL 直接当作所有股票的 TTM 指标。授权全市场行情、复权和盘口保留配置门槛，不虚构授权能力。

## 边界

本清单不是全市场实时性保证。报告期年龄规则只能识别明显陈旧，不能证明某企业尚未披露新一期；网站聚合源可能共用上游；官方日度估值也不是实时估值。未配置的来源继续返回明确缺失原因。完成记录会补充实际变更、测试及未解决项。
