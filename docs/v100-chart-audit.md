## 已实现

- 统一按报价交易日解析上一交易日常规收盘，计算 headline 主涨跌；PRE/POST 分项使用各自基准。缺失或冲突基准时保持最新价格，派生涨跌为空。API、恢复缓存和卡片一同输出基准日期、来源与状态。
- 图表独立投影常规时段，历史、服务器采样、实时尾点、横屏详情与 PNG 导出使用同一过滤结果。默认展开完整会话时间轴，未来时段空白；缺口断线。五日按五个真实交易日分槽，未取得的日期保留缺失状态。
- 日线与周/月/年成交量按已核验来源单位归一，旧缓存中的原量按新版规则恢复。区间量缺失仍为 `null`，不拿累计量或报价采样次数填柱。盘中 Yahoo 5 分钟 OHLCV 可显示同源量柱；Nasdaq 价格点仍明确缺区间量。
- 新增双击或展开入口的横向详情：报价概要、盘前盘后变化、常规价格图、量区、估算均价线、日/五日/日周月年导航、真实一档盘口只读投影、逐笔片段与片段成交统计。没有交易按钮。桌面与手机横持布局、全屏及方向锁尝试、拒绝后的整页 CSS 旋转、逆变换光标、返回/Esc/关闭和焦点恢复已接入。
- 新增每标的最多 1000 条的原始成交事件缓存；Finnhub 与 Alpaca 流可写入，Alpaca 取消/更正保留状态。连接与数据覆盖标识不会宣称全市场完整逐笔。
