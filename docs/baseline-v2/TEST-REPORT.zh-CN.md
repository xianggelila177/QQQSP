本版验收基于功能迁移，而不是“旧版 134 个文件全部通过”的声明。91 个保留回归文件通过，18 个新增核心测试通过；43 个旧架构套件显式退役，不计为通过。详细理由及替代路径见 `tests/retired-v72.json`。

## 三、浏览器体验与秒级年龄

概况：使用实际前端打包代码和实际 Chromium，以离线固定数据驱动；浏览器环境限制无法访问本地 HTTP 地址，因此浏览器网络采用接口替身。真实 HTTP/SSE 传输由第二节单独验证，不把这两者描述为穿透真实上游的端到端测试。

每种线程场景先等待 0.5 秒，再采样 4.6 秒。最大间隔只代表本次短时前台观察。

| 场景 | 年龄变化次数 | 最大相邻变化间隔 | 健康状态行情轮询请求 |
|---|---:|---:|---:|
| 正常工作线程 | 5 | 1008.40 毫秒 | 0 |
| 工作线程静默 | 4 | 1007.60 毫秒 | 0 |
| 工作线程报错 | 5 | 1000.10 毫秒 | 0 |

正常场景还检查：单卡事件不抹掉其他卡片；只有展开的卡片请求新闻；折叠新闻和宏观不请求；主动断开事件流后启动 HTTP 兜底，恢复事件流后不再轮询；添加和移除标的可用；指定红框文字不存在；无 JavaScript 页面错误。

六种宽度 320、375、768、1024、1440、1730 像素下，测试页面没有整体横向溢出。截图只含模拟数据，不代表市场价格。

证据：`evidence/browser-results.json`、`evidence/browser-check.log`、`evidence/v2-desktop.png`、`evidence/v2-mobile.png`。

## 四、体积与性能证据

概况：本次验证的是具体请求和计算路径，不估算未经测量的并发承载能力。

六项预压缩静态资源原始合计 160347 字节，Brotli 合计 47933 字节，体积减少约 70.1%。这是指定静态资源的压缩比，不是 CPU、内存或整站延迟提升比例。构建时一次压缩，服务读取压缩文件。

健康事件流期间没有浏览器行情轮询，年龄计时不触发请求。原始历史数据版本相同时，重复请求复用聚合结果；缓存字节预算采用保守估算，不为每次预算计算完整序列化历史数据。没有高并发压测，也未给出高并发数字。

## 五、验证边界与结论

概况：可部署源码已经形成，但生产环境相关事项未被本地结果覆盖。

未验证真实行情凭据、账户覆盖及权限，未验证公共网站当前地域可用性，未实测 Cloudflare 隧道、systemd 安装、Docker 构建、设备长期后台冻结或 48 小时稳定性。安装脚本完成语法检查，实际服务启停由本机 HTTP 测试验证，不等同于执行 systemd 安装。

旧版全部测试可通过 `npm run test:legacy` 查看，其中被明确替换的全局实例/轮询/中继/准入及旧工具链套件仍可能失败。本版没有声称全部旧混合断言已等价迁移。

结论：已执行的保留回归、核心测试、接口与浏览器检查通过；上线应以新端口运行并验证实际来源与事件流后再切换原域名，保留旧版作为回退。
