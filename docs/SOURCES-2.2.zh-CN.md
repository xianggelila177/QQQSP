# QQQSP 2.2 历史数据来源说明

本次独立历史适配以公开网站的响应格式为基础，使用项目原有标准库 HTTP 传输与冷却模块；没有引入第三方运行时依赖。下面是实现依据，不是来源服务等级、使用授权或持续可达性的承诺。

## 一、历史来源路径

概况：报价来源与历史来源不必相同，图表会标注实际历史来源；可用数据不跨来源拼接。

| 范围 | 路径 | 使用方式 |
|---|---|---|
| 既有全球历史 | Yahoo chart | 保留，出现错误/空数据时尝试适用备源 |
| 美国普通股、部分 ETF | `https://api.nasdaq.com/api/quote/{symbol}/historical` | 日 OHLC；assetclass 按证券类型选择 |
| 美国普通股、部分 ETF | `https://api.nasdaq.com/api/quote/{symbol}/chart` | 来源提供的时间与价格分时，不伪造量 |
| 美股、内地、香港部分证券及明确映射指数 | `https://push2his.eastmoney.com/api/qt/stock/kline/get` | klt=101、fqt=0；原日线再聚合周/月/年 |
| 韩国本地股 | 现有 Naver 韩国日线与分时适配 | 继续按韩国本地代码读取，不换成美国存托证券 |

东方财富命名空间根据证券市场确定，返回 code 与 market 必须一致；美股未知交易所允许有限候选发现，主机 429/403 后不继续轮换命名空间发请求。其他市场无适配来源时保留原路径并清楚显示失败。

## 二、公开实现参考

概况：以下代码用于核对 URL、参数和字段顺序；本实现未复制整套外部项目，也未宣称这些网站提供无条件公开 API 合约。

- AKShare 的东方财富历史函数，`stock_us_hist`、香港/内地历史：
  https://github.com/akfamily/akshare/blob/master/akshare/stock_feature/stock_hist_em.py
  字段包含日期、开盘、收盘、最高、最低、成交量；klt 区分周期，fqt 区分来源复权选项。本版选原始日线后自行聚合，并保留“来源复权口径未确认”标记，不宣传为经过独立审计的复权数据。
- go-stock 的韩国来源实现：
  https://github.com/ArvinLovegood/go-stock/blob/dev/backend/data/korea_stock_api.go
  供既有 Naver 格式与本地证券路径参考。
- 本项目已存在的 Nasdaq 报价补充模块：`lib/providers/nasdaq.js`。2.2 将独立历史能力接入真正的 `/api/history`，不再仅作为报价补充附件。

## 三、刷新、限流与覆盖

概况：高频报价与低频历史分开，历史缓存不是每秒请求。

独立来源分时缓存 60 秒，日线缓存 5 分钟；同证券周期共享请求结果，需要更长范围时补取。来源返回 429 时遵守等待信息与主机冷却，不轮换代理或出口规避限制。年度历史受来源保留区间和本地 45 年窗口约束，图表显示覆盖与截至日期，不能把较短数据当作上市以来完整历史。

本轮执行环境没有外网 DNS 连通性，无法在容器内完成上述网站真实行情联调。接口解析、主备切换、限流、空数据和绘图由受控样本验证。请在实际服务器运行 `node ops/history-smoke.mjs` 核实真实结果；这是部署验收，不会注入示例价格。

## 四、结论

概况：免费网页接口可提高来源冗余，但不能给出永久稳定、全市场覆盖或永不 429 的承诺。全部来源失败时保留可用旧缓存并显示失败与冷却，不构造历史数据。
