# QQQSP 2.7 — 分时时间归一化与完整发布版

## 一、交付概况

完整源码、已构建并预压缩的前端、部署与回滚脚本、可复现测试。应用2.7.0，资源80。运行仅需Node.js 22.16或更新版本，无需npm install，单用户、单进程、零第三方运行时依赖。

本包独立包含2.5后台宏观采集、上一轮2.6的解压/编码/备用源恢复修复，以及本轮Nasdaq图表时间纠正。无需先安装2.6或手工复制补丁。分时图和报价统一显示北京时间，周期K线仍使用交易所交易日。

## 二、部署与验收

```bash
sudo env NODE_BIN="$(command -v node)" bash ops/install.sh /opt/qqqsp-v2 8568
node ops/smoke.mjs http://127.0.0.1:8568
node ops/chart-time-smoke.mjs http://127.0.0.1:8568 LITE,AAOI
node ops/macro-smoke.mjs http://127.0.0.1:8568 --stream
```

升级保留shared/.env、state和logs。已有PORT优先于安装参数，安装器更新qqqsp-v2.service，不修改隧道。仅失效旧Nasdaq分时缓存，不删除报价、日K、宏观检查点或自选。完整说明见根目录《部署说明.md》。

## 三、时间语义与交付边界

Nasdaq优先解析来源时间标签，显式时区优先，否则采用America/New_York及来源日期。不是全部加四小时。纯数值横坐标无标签时不猜测偏移，保留并提示待核验。真正陈旧的历史仍显示原时间；价格时间、来源检查时间、历史时间三者不互相替代。

测试及过程见docs/TEST-REPORT.zh-CN.md与docs/REPAIR-2.7.zh-CN.md。受控响应能证明解析/绘制链路，不代表目标服务器公共来源持续可达。上线使用时间诊断与宏观--diagnose/--live检查实际来源。生产入口不加载测试价格。
