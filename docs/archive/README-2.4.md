# QQQSP 2.4：宏观证据与原油观察版

本包包含完整源码、已构建并预压缩的前端、安装及回滚脚本、自动化测试与验证记录。保持单用户、单进程、零 npm 运行时依赖，不引入数据库、模型服务或分布式组件。应用版本 **2.4.0**，静态资源序号 **77**。

## 一、部署

运行要求 Node.js 22.16 或更新版本，推荐 24；本轮实际测试环境为 22.16.0。无需 `npm install` 或重新构建前端。

```bash
unzip qqqsp-v2.4-source.zip
cd qqqsp-v2.4
sudo env NODE_BIN="$(command -v node)" bash ops/install.sh /opt/qqqsp-v2 8568
node ops/macro-smoke.mjs http://127.0.0.1:8568
# 在目标服务器核验真实资讯与五个观察来源：
node ops/macro-smoke.mjs http://127.0.0.1:8568 --live
```

已有安装时保留 `shared/.env`，命令中的端口不覆盖旧配置。实际目录或端口不同时请使用实际值。详情见 [部署说明](部署说明.md)。

## 二、界面与判断升级

宏观资讯与全球市场目录调换位置：搜索框之后是宏观资讯，行情卡片之后是全球市场目录。宏观保持默认折叠；展开且页面处于前台时才自动读取，折叠不继续采集。

宏观资讯不再用标题里正面、负面关键词计数决定整条新闻“利多/利空”。每条显示针对纳指100、原油等资产的条件影响，并展开提供来源证据、适用条件、反向解释、缺失信息和发布时间。优先显示通胀、能源及利率相关事件，可切换全部资讯。原有个股卡片的标题情绪参考未在本次改写。

新增纳指100期货、WTI、布伦特、美债10年指标、美元五个观察项。价格和来源成交时间分开保存；积累约15分钟、时间足够新且端点相互对齐后，才提供同窗变化。油跌、纳指涨仅描述共变，不能证明资金转移或押注CPI。

## 三、来源与运行成本

新增美国劳工统计局 CPI、美国能源信息署能源资讯官方订阅，保留原官方公告与聚合快讯。宏观新闻生产链路不再调用 Yahoo 新闻搜索/认证兜底，避免抢占其指标与历史数据的共享额度；宏观指数价格仍可能使用 Yahoo，遵守原有冷却。

默认不需要新增密钥。需要结构化经济日历时，可在服务端 `shared/.env` 增加自己的 `TE_API_KEY`。这需要对应的 Trading Economics 权限；没有密钥时明确显示未配置，不使用公共密钥或模型预测冒充一致预期。

跨资产约30秒检查，新闻界面约60秒检查；订阅来源有独立缓存。原股票报价与每秒年龄显示不改慢。详见 [宏观研判与来源说明](docs/MACRO-METHOD.zh-CN.md)。

## 四、验证与边界

本版运行完整保留回归、核心测试及四组真实 Chromium 浏览器测试；故障过程和最终日志在 `docs/evidence/v2.4/`。完整结果见 [测试报告](docs/TEST-REPORT.zh-CN.md)。

测试使用受控上游样本检验真实代码与接口，生产入口不加载样本。本包不是经过收益回测的交易预测模型；不声称有胜率，也不声称全天候拥有全部实时权限。真实上游连通性、付费账户及 systemd/隧道安装未在目标服务器执行，部署后使用上述 `--live` 命令核验。
