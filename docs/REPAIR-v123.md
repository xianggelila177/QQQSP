# v123 查询范围、更新成本与导航修复

应用版本 2.16.5，静态资源版本 123。保留现有 Node 单进程、来源适配器、独立历史状态与 SSE 交付架构。本次没有改变来源配额、持久自选、历史复权规则或交易数据授权。

## 行为变化

- 历史已有近期缓存时，market-context 会检查 `extent.satisfied`，在允许等待的预算内通过原有历史服务补齐请求范围。0ms查询仍仅读缓存；已确认历史起点、限流冷却、来源窗口限制及拥塞时的部分结果继续保留。
- 报价签名忽略逐次变化的评估时钟，同时比较真实的报价/来源过期原因与会话状态。来源检查、价格、静默连接过期、开收盘等变化仍可通知；对外质量元数据保留。
- 报价批次先落位全部证券，再计算一次共享刷新策略；每秒报价年龄刷新和手动刷新筛选按批复用。下一批次重新计算，以响应交易时段变化。
- 采样筛选按点数组、版本、币种及交易时段内容复用派生数组和覆盖统计；状态文字仍更新，数据或日历内容变化正确失效。
- 详情主图按数据、版本、视口、图表设置、币种/汇率、时段、尺寸与DPR失效。无变化的历史图复用已有计算；活跃常规交易时段的渐进时间轴仍按时间更新。Canvas仅在实际尺寸变化时重设，摘要、质量、分页和游标继续更新。
- 产品和证券使用可辨认的标题层级，证券区域关联标题；增加“跳至自选行情”键盘入口，保留既有外观与焦点管理。

## 验证范围

聚焦测试覆盖历史补齐/游标/0ms/起点/冷却/容量回退、报价去重与实际过期边界、100卡批次策略、采样缓存失效、详情历史更新及绘图交互。发布时另运行构建、语法与预压缩一致性检查，以及隔离发布包启动和线上状态/资源检查。未运行全量测试或公网负载测试。

合并后12个相关测试文件共101/101通过；包含交叉审查补充的交易日切换清除草稿图层，以及intervalUnknown双向变化回归。`npm run build`通过，`npm run check`通过604个脚本检查和19个Shell LF检查；Windows不执行Bash语法检查，发布阶段在Linux补查。

入口探针确认：100卡报价批次和每秒刷新各计算一次策略；60根历史图连续30次仅报价更新，不增加主图计算、主图绘制或Canvas尺寸赋值。此类操作计数不代表线上FPS/P95或整体加速倍率。

旧 `v97-quote-freshness.test.mjs` 有3项基线失败，涉及已变更的单一quoteMeta文案和指数发布假设；在原v122源码隔离重跑可复现，未改动旧断言掩盖失败。当前报价元信息契约由 `data-quality-quotes.test.mjs` 验证。

## 有意保留的边界

采样和历史缓存遵循现有不可变数组/revision契约，不为非法的无版本中部原位修改增加全数组hash。100ms调度、行情表/联动工作台、卡片高度重设计和新增研究数据源仍为后续候选，不在本次修复中扩展。

部署保留共享配置、密钥与API-key状态、自选、日志、服务/代理/隧道配置和前一发布回滚入口。数据来源局部缺失与应用就绪分开报告；静态资源检查不等同浏览器视觉验收。
