# QQQSP 2.4 宏观研判与来源说明

## 一、产品目标

本次把宏观资讯由“正负关键词计票”改为“来源证据＋资产对象＋条件传导＋同步市场观察”。交付的是轻量的规则辅助阅读与数据核对工具，不是经过收益回测的交易模型，不输出胜率，也不把价格相关性当作资金流或因果证据。

用户举例“原油获利了结的资金转去押注CPI、推高纳指”在本版被当作待验证假设。单靠原油跌、纳指涨，缺少识别具体资金、交易动机与事件顺序的证据。程序不能证明这一解释，不能将其作为已核实新闻推送。

## 二、研究结论及实际采用方式

本节区分来源实际描述与本项目的设计取舍。资料核验日期2026-09-11。没有从外部项目复制模型权重、完整文章或带许可限制的数据集；没有抓取交易所页面来伪造交易所评级。

## 三、事件规则如何产生有边界的判断

所有影响标签都是本地条件推断，不是交易所背书。没有足够信息时输出“待验证”，而不是用中性代替“不知道”。

| 事件样例（机制说明，非当前市场事实） | 本版输出 |
|---|---|
| 美国同月、同口径CPI实际值低于报道预期 | 纳指条件偏利多；显示差值、共识时点未核验、利率和增长条件 |
| CPI低于前值但没有预期 | 待验证；不伪造通胀意外 |
| 总CPI低于预期但核心高于预期 | 影响分歧；不把分项加总成单一利多 |
| 原油供给恢复 | 油价条件偏利空，纳指在需求稳定和成本缓和条件下偏利多 |
| 原油需求恶化 | 油价条件偏利空，纳指影响分歧；成本下降可能伴随盈利或增长担忧 |
| 原油减产/供应中断 | 原油条件偏利多，纳指在能源成本及利率上移条件下偏利空 |
| 原油获利了结、资金转入纳指押注CPI | 待验证假设；要求可追溯资金/持仓与发布前预期证据 |
| 传闻、否认、未发生预测、过期新闻 | 不作为当前已确认冲击；显示缺失信息或历史背景 |

分析范围是标题及最多1800字符订阅摘要，并不声称阅读全文。语义识别采用有限的中英文规则，复杂表达可能无法识别或被过度谨慎地归为待验证；不是完整自然语言理解。官方身份必须同时满足官方标志与受认可原始域名，转载不能仅凭标题包含“官方”获得官方级别。

每条保留证据范围、资产对象、条件、反证、信息缺口与原始链接。相同链接或同日相同标题去重，保留转载来源，但不把转载次数当独立证据数量。多个新浪快讯共享聚合页不会互相覆盖。

## 四、原油与纳指的同窗观察

观察固定五个来源身份，不额外占用自选额度，也不逐秒抓取新闻。

| 对象 | 程序证券代码 | 显示口径 |
|---|---|---|
| 纳指100期货 | NQ00Y.FUT | 东方财富对应连续序列，点 |
| WTI原油 | CL00Y.FUT | 东方财富对应连续序列，美元/桶 |
| 布伦特原油 | BZ=F | Yahoo对应连续序列，美元/桶 |
| 美债10年指标 | ^TNX | 来源原值及数值差，不猜测缩放为收益率百分比/基点 |
| 美元指数 | DX-Y.NYB | 来源指数点位 |

来源成交时间与成功检查时间始终分开。最多保留每项90条真实采样、最近30分钟；同一来源或合约身份改变时清空该项比较窗口，不拼接不同连续序列。没有源时间、源时间超过2分钟、明确延迟源、恢复缓存、错误状态都不能参加同步比较。

滚动15分钟窗口的起点要求在目标时刻前后60秒内。跨资产起止时间还需相差不超过60秒。没有有效起点时显示积累中，不拿各自昨收涨跌幅来冒充同步资金轮动。窗口跌涨阈值0.1%只是提示阈值，未以收益回测校准，不是交易触发阈值。

这些序列的交易时段、换月、延迟和授权并不完全一致，因此可比窗口不保证全天存在。本版不自动识别每一笔真实合约换月，未提供合约身份时会明确保留口径未核验的提示。程序不能识别资金身份。

## 五、CPI实际与预期的时点管理

默认模式可从明确的报道中提取美国、月份、总/核心、月率/年率以及实际值和报道预期。缺一项就不计算。前值不能充当预期；季调、修订与报道共识是否发布前冻结仍需核对。

可选 `TE_API_KEY` 模式从结构化日历读取事件时间、参考期、实际值、一致预期与前值。`Forecast`是经济学家共识，`TEForecast`是来源自己的预测，绝不互相替代。`Importance`只是高/中/低重要性，不是方向或获利概率。`Previous`为适用修订后的前值，`Revised`保留修订前数值，分别显示。

只有事件计划时间明确、实际值为空、请求发生在发布前，才记录本机预期快照。事件身份包含编号、参考期和计划时间，不能跨月份共用。发布后优先使用本机已采集预期，不用更新后的Forecast篡改旧快照。

只为明确参考期的通胀月率/年率百分数计算“实际−预期”百分点差。库存、议息结果不能机械套用“越低越利多”；核心与总指数需分开观察。本机记录只证明何时读到了供应商字段，不是供应商审计的历史数据库；内存重启、折叠或未打开时不会补造历史记录。

## 六、轻量化与请求节奏

所有采集由宏观展开、页面前台的HTTP检查驱动。没有新增后台定时器、付费模型请求、数据库、消息队列或每用户独立采集进程。

| 链路 | 默认频率/缓存 |
|---|---|
| 浏览器宏观资讯刷新 | 约60秒；折叠/隐藏停止 |
| 跨资产上下文检查 | 约30秒；首轮来源处理中可5秒读取一次本地状态 |
| 五个宏观价格来源 | 每项至少30秒；遵守来源更长声明及失败冷却 |
| Google主题订阅 | 5分钟缓存 |
| 新浪快讯 | 1分钟缓存 |
| BLS CPI订阅 | 5分钟缓存 |
| EIA能源订阅 | 15分钟缓存 |
| 其他原有官方源 | 30分钟缓存 |
| 可选结构化日历 | 普通5分钟、已知事件前后15分钟内1分钟 |

价格来源沿用共享请求池和主机冷却；并发客户端不各自建立一套宏观采集。宏观新闻正式链路禁用Yahoo搜索兜底，避免它的认证/搜索失败挤占指标与历史预算。普通失败至少60秒再试，429采用更长的服务器等待；日历失败至少5分钟，401/403需修正凭据后重启。不承诺永不出现429。

原股票、韩国市场与期货的搜索、报价、历史链路继续回归；本版没有提高自选数量、引入新的交易下单能力或创建外部推送订阅。“推送”在此仍指面板内展示更新，未增加短信、邮件或机器人推送。

交付满足本次功能的代码与受控测试验收。尚未证实真实账户数据覆盖、生产网络稳定性或任何统计上的择时收益。使用时以证据、原始资料及显示的时间状态判断，不因单一红绿标签作出交易结论。
