# 2.1 实现说明

## 概况

以完整 2.0 源码为基线，整合上一轮六个模块，并补齐此前未保存的组装、调度、前端控制器和配置改动。没有增加运行依赖或多用户基础设施。

## 关键模块

| 模块 | 本版责任 |
|---|---|
| catalog-search / korean-search | 本地多市场别名，以及未知韩国六位代码的来源核验 |
| sina-quotes | 新浪批量响应解析、交易时间、币种及价格字段 |
| fast-polling | 美国/中国市场主备顺序、单源单批在途、独立采集间隔 |
| batch-snapshot | 腾讯香港支持、韩国 Naver 批量与声明间隔 |
| host-gate | 已有来源共享限流、Retry-After、最小间隔；未新增外部组件 |
| snapshot-service | 一秒目标调度、从请求开始计时、开市恢复、慢历史独立 |
| naver-history / history-source | 韩国历史读取与按证券身份路由，不将日线当分时 |
| chart-enricher | 价格已有时只补慢图表；缓存和失败保留 |
| panel-chart-engine/controller | 缺历史的真实观察点、单点绘制、旧交易日提示 |
| app.js | 显式组装上述服务；服务器事件推送沿用原有单实例引擎 |

## 范围与边界

保留上版 optional 实时账户适配、资讯懒加载、币种、自选与本地恢复。未实施原规划中的多用户队列、灰度流量、数据库或框架迁移。没有免费源的服务等级承诺；一秒调度不会凌驾于上游配额或等待时间。

## 结论

已构建与测试的完整程序集在当前包内。真实账户和真实网络覆盖需以部署环境为准；此前未完成的文件集不再需要手工拼接。
