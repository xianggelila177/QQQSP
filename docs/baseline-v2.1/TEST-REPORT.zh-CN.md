本版新增 24 个核心用例，上版核心 18 个用例继续保留；合计 42。

覆盖新浪同源批量、常规与盘前交易时间、来源检查时间独立、韩元与美元身份隔离、腾讯香港币种、未知韩国六位代码核验、Naver XML 分钟/日线解析、累计成交量差值、历史单飞缓存、日线不冒充分时、空历史单点绘制、非完整采样标注、源切换重置、旧历史保留与币种拒绝、失败备源仍每秒采集、开市恢复和 Retry-After 不被绕过。

完整应用组装用例使用生产数据路径、注入网站格式响应、真实本地 HTTP：两只美股共用一个新浪请求；韩国本地股独立报价与历史；约 3.4 秒内观察到 3～4 个新浪批次，相邻间隔断言小于 1.3 秒；重复读取自有缓存接口不会放大上游请求。这个结果不是互联网延迟保证。

确定性调度测试验证：请求耗时 200 毫秒时仍按请求开始的 0、1000、2000、3000、4000 毫秒启动，而不是逐次叠加请求耗时；休市切换开市立即到期，但不会绕过来源限流等待。

使用已构建的 `public/panel.bundle.js`，真实 Chromium，无页面 JavaScript 异常。

每个场景仅观察 4.6 秒，是短时前台测量，不是长期后台节流或操作系统冻结保证。事件流健康时，浏览器测试中没有常态行情轮询请求；断流后能启动缓存读取兜底，恢复后停止兜底；折叠资讯不继续请求。

六种视口 320、375、768、1024、1440、1730 像素通过整体横向溢出检查。新增场景分别显示韩国普通股的韩元历史、美国存托证券的美元单点采样，以及旧日分时被当前真实观察替代；单点能绘制，成交量保持缺失，报价更新后采样更新。

## 五、部署验证与限制

生产 `server.js` 在无密钥的临时运行目录中启动成功；`/readyz` 返回服务就绪、报价尚未就绪；市场目录、来源状态可读取；事件流返回合法的 PENDING 冷启动快照；SIGTERM 后进程以状态 0 退出。该启动测试没有模拟真实价格为在线报价。

Bash 安装与回滚脚本通过语法检查；未将本地环境的检查称为真实 systemd 安装成功。最终 ZIP 另进行解压、逐文件 SHA-256、构建一致性及解压后生产入口启动检查，结果见交付外层的包验证记录。

## 六、结论

完整程序、构建资源与部署脚本已包含在本包，可以直接启动或安装。没有依赖未交付的补丁。免费来源的限流、延迟、权限与不可达状态仍可能出现；程序通过共享批次、独立历史缓存、来源冷却、备源和真实状态展示降低影响，而不是承诺每秒必有新成交或永不返回 429。
