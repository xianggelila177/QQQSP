# QQQSP 2.11 完整源码与部署包

应用版本 **2.11.0**，静态资源版本 **86**。本包基于用户提供的 **2.10.1／v85** 全量源码，合入基础信息扩展、重新生成前端及预压缩资源，并包含可复现测试与部署脚本。不是差异补丁，不需要再与旧版手动合并。

## 一、运行概况

生产运行要求 Node.js 22.16 或更新版本，保留单进程与零运行时第三方依赖。已构建前端随包提供，**生产启动无需执行 npm install**。

```bash
unzip QQQSP-2.11.0-v86-full-source.zip
cd qqqsp-v2.11
bash start.sh
# 默认本地地址：http://127.0.0.1:8567
```

启动前可按需复制 `.env.example` 为 `.env` 并填写自己的配置。升级时保留已有配置及状态，不能用空模板覆盖凭据。长期运行、Linux 安装器、容器、端口、持久自选与回滚见根目录 `部署说明.md`。

## 二、本版新增内容

基础信息位于图表下方、相关资讯上方，默认显示 16 项，展开后为 24 项；所有卡片同步展开，缺失项保留位置，数值右对齐，窄屏自适应。

| 范围 | 内容 |

| 展开指标 | 量比、委比、年度市盈率、滚动市销率、滚动股息、滚动股息率、每手数量、交易所 |

另外修复了外层调度与来源缓存起点相差 1 毫秒时可能出现的整轮延迟，并保留来源限流重试约束。

原有实时行情、报价年龄、分时／日周月年图表、报价采样、宏观资讯及自选机制继续保留。本版财务资料更新不重置报价或来源检查时间；迟到旧报价先被拦截，再用保留下来的价格计算衍生指标。

## 三、数据与部署边界

默认财务来源为 Yahoo 摘要；配置用户自己的 Finnhub 凭据后可补充明确的财务字段。资料默认缓存 6 小时，失败退避；超过最大保留期隐藏过期财务数值。

**指标有位置不等于每个来源都有数据。** 量比、委比、每手数量等默认来源未提供合格数据时显示缺失；不采用一档盘口冒充完整委比，不以最新价乘成交量伪造成交额，也不将缺失市盈率标为亏损。基金、指数和期货不套用公司估值字段。

预览及测试中的行情全部为离线样本，不是真实市场数据。包内不包含私人配置、真实凭据、运行状态或 `node_modules`。真实公网来源、付费权限、目标服务器与长期负载需要在部署环境验收。

## 四、构建与测试

构建、语法校验、核心及保留回归均可用 Node.js 自带能力运行。浏览器测试另外需要 Python Playwright 和 Chromium，属于开发验收环境，不是生产运行依赖。

```bash
npm run build
npm run check
npm test
npm run test:fundamentals
CHROMIUM_BIN=/usr/bin/chromium npm run test:fundamentals-browser

# Linux 逐文件完整性核验
sha256sum -c SHA256SUMS
```

`npm test` 包含当前维护回归与核心测试；原有显式退役文件不计为通过。实际本轮结果、环境与未执行项见 `docs/TEST-REPORT.zh-CN.md`。原始日志、浏览器报告和预览见 `docs/evidence/v2.11-release/`。
