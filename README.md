# QQQSP 2.3：期货搜索与行情接入版

本包包含完整源码、已构建前端、部署与回滚脚本、测试代码和验证说明。保持单用户、单进程、零 npm 运行时依赖；不需要另行拼接旧版补丁。运行要求 Node.js 22.16 或更新版本。

## 一、部署

前端资源已构建，应用版本为 **2.3.0**，静态资源序号为 **76**。无需 `npm install`。

```bash
unzip qqqsp-v2.3-source.zip
cd qqqsp-v2.3
sudo env NODE_BIN="$(command -v node)" bash ops/install.sh /opt/qqqsp-v2 8568
node ops/futures-smoke.mjs http://127.0.0.1:8568
# 在目标服务器验证真实报价和日、周、月、年历史：
node ops/futures-smoke.mjs http://127.0.0.1:8568 --live NQ00Y.FUT
```

安装器保留现有共享配置；已有安装时，命令里的端口不会覆盖 `shared/.env`。实际安装目录、端口不同，应使用真实值。完整步骤与回滚见 [部署说明](部署说明.md)。

## 二、新增功能

本版接入期货的证券身份、搜索、报价、历史和前端显示，而不是只增加别名。

输入 `NQ0W`、`NQW00`、`NQW00:CME_EMINIS`、`纳指夜盘`，会得到分别标注来源的 CME 纳指100期货相关候选。**NQ0W 没有被核实为标准代码**；不会将它自动当作纳斯达克综合指数或捏造名为 NQ0W 的行情。

直接可用的面板代码为 `NQ00Y.FUT`（东方财富 NQ00Y 命名空间）和 `NQ=F`（Yahoo 命名空间）。`.FUT` 是本面板区分来源的后缀，并非交易所代码。这两条连续序列独立保存，不互相覆盖或拼接。

本地目录由 68 条扩充到 **84 条**：保留原条目，并加入纳指100、标普500、道指、黄金、白银、铜、原油、天然气八个品种的两个来源入口。新增“国际期货”浏览分区；原20个市场仍保留。目录数量不代表全网搜索上限。

“查询更多来源与具体合约”只在用户点击时访问远端，返回已登记品种的具体月份候选，同时保留原有股票搜索。一次读取一个对应交易所分类页面，不后台遍历全站；远端只返回部分记录时标记部分目录。

## 三、价格、图表和限制

期货不套用美股股票的开闭市时间；交易日历尚未核验时明确显示未知，不因美股休市停止读取。股指期货显示“点”，不是乘以合约乘数后的名义金额，也不作人民币换算。

日、周、月、年K共用同一来源的历史链路。东方财富期货暂无专用历史分时接入：有来源成交时间时，分时显示本次收到的真实报价采样；没有时间时不制造采样。Yahoo期货使用其图表来源提供的分时数据。两个来源均不保证覆盖所有日期。

报价年龄保持每秒更新；新增期货公共报价默认每 **5秒**尝试刷新，目录备源默认30秒。原股票刷新调度不变。429遵守服务器等待时间，不通过换域名绕过限流。Google与TradingView在本版仅用于代码检索提示，不抓取其页面价格。新浪的NQ页面注明CFD，因此没有作为CME期货的同价备源。

## 四、验证与交付

本轮完整回归 **91个文件通过**，核心测试 **79个用例通过**；期货新增17个用例包含先失败后修复的证据。实际浏览器验证搜索、加入自选、月份合约、四档K线、真实采样以及六种屏幕宽度。具体边界见 [测试报告](docs/TEST-REPORT.zh-CN.md)，代码与来源对应关系见 [实现说明](docs/IMPLEMENTATION-NOTES.zh-CN.md) 和 [来源说明](docs/SOURCES-2.3.zh-CN.md)。

这些是受控上游测试和本地启动结果。构建环境访问上游API时域名解析失败，**未宣称真实东方财富/Yahoo期货接口已在你的服务器联调成功**。部署后应执行带 `--live` 的验收命令；所有来源失败时显示错误，不插入测试价格。

为遵守发布边界，GitHub 上传副本不包含 docs/evidence 下的日志、截图和运行证据；完整证据只作为本地交付校验材料保留。
